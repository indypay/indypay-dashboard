## 1. Initiate Payin Transaction

Using this API we can create the payment gateway URL. Once we get a successful response in the API, the customer can get payment request on there UPI App.

**API URL:** `{{base_url}}/api/v1/payments/payin/create`  
**Method:** POST

### Headers

1. `Content-Type: application/json`
2. `Authorization: Basic Auth`
   - Username: `<Client ID>`
   - Password: `<Client Secret>`
   - Secret Key: Generate Secret Key from Developer Section
   - Client ID: Generate Client ID from Developer Section

### Request Body

```json
{
  // "orderId": "test_12345890", // NO NEED TO PASS (Bank will generate and send in response)
  "amount": 100,
  "name": "Test",
  "email": "test@RupeeFlow.in",
  "mobile": "9999900000",
  "vpa": "9999900000@ybl"
}
```

### Response Body

```json
{
  "statusCode": 201,
  "message": "Data Received",
  "success": true,
  "data": {
    "orderId": "test_12345890",
    "message": "Payment Request Sent Successfully"
  }
}
```

### cURL

```bash
  curl --location '{{base_url}}/api/v1/payments/payin/create' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Basic a2V5XzAxa2V5XzAxSkXXXXXXXXXXXX2V5XzAxSk' \
  --data-raw '{
    "amount": 100,
    "name": "Test",
    "email": "test@RupeeFlow.in",
    "mobile": "9999900000",
    "vpa": "9999900000@ybl"
  }'
```

#### NOTE:

- Order ID: A unique order ID needs to be generated by a merchant (Mandatory).
- Minimum Amount: 100. It is the value of the purchase. Eg: 100.00 (Decimal is not mandatory).
- Name: Customer’s Name.
- Email: Customer’s Email Address.
- Mobile: Customer’s Mobile Number.

## 2. Check Payin Transaction Status

Using this API we can get the status of the payin transaction.

**API URL:** `{{base_url}}/api/v1/payments/payin/status`  
**Method:** POST

### Request Body

```json
{
  "orderId": "test_12345890"
}
```

### Response Body

```json
{
  "statusCode": 200,
  "message": "Data Received",
  "success": true,
  "data": {
    "orderId": "test_12345890",
    "status": "SUCCESS" | "PENDING" | "FAILED",
    "txnRefId": "094320545671"
  }
}
```

### cURL

```bash
  curl --location '{{base_url}}/api/v1/payments/payin/status' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Basic a2V5XzAxa2V5XzAxSkXXXXXXXXXXXX2V5XzAxSk' \
  --data-raw '{
    "orderId": "test_12345890"
  }'
```

## 3. Payin Webhook Response

When merchant have configured there webhook URL to our dashboard, we will send webhook response to there endpoint wherever payment status will change/update by Bank.

### Request Body

```json
{
  "orderId": "test_12345890",
  "status": "SUCCESS" | "PENDING" | "FAILED",
  "amount": 100,
  "txnRefId": "094320545671", // UTR
}
```

#### NOTE:

- Order ID: A unique order ID generated by the merchant.
- Status: "SUCCESS / FAILED / PENDING"

## FAQ

1. **How to generate Client ID and Secret Key?**

   > To generate Client ID and Secret Key, login to your dashboard and go to Settings > Developer Section > Click on Generate > New Client ID and Secret Key is Generated.

2. **How to whitelist the IP address?**
   > To whitelist the IP address, go to Settings > Developer Section > (Scroll down) Enter IP Address > Click Add.
